Guide de prise en main · Cameroun (+237, FCFA)

Prise en main TontApp

Tontines et projets collectifs, de l'invitation au journal d'audit. Chaque parcours a été filmé en conditions réelles, sur un téléphone Android et dans le navigateur. Le projet collectif est celui de votre classeur Excel de cotisations, importé tel quel.

F

L'argent reste hors de l'application. Les membres remettent leur cotisation au gestionnaire, en espèces ou à la banque. TontApp tient le registre : le gestionnaire saisit le paiement, le valide après avoir vérifié le reçu, et chaque action est inscrite dans un journal impossible à modifier sans que cela se voie.

Qui fait quoi

Mobile + web

Gestionnaire

Crée la tontine, invite par code, l'active, gère les tours et relance par SMS. Sur le web, il encaisse et valide les cotisations, accepte les adhésions tardives, gère les projets collectifs et règle leurs paramètres.

Mobile

Membre / participant

S'inscrit avec son numéro et un code OTP, rejoint une tontine ou un projet avec un code, choisit son palier, suit ses échéances et voit ses paiements passer à « validé ».

Web

Administrateur

Supervise la plateforme : cotisations validées de la semaine, SMS, liste des tontines, alertes (chaîne d'audit rompue, tour en retard, SMS en échec).

Démarrer en local

Prérequis : Docker, le SDK .NET 10, Node 20 et plus, et pour le mobile le SDK Android avec un téléphone branché en USB (débogage USB activé). Toutes les commandes se lancent à la racine du dépôt.

make up
Démarre PostgreSQL (port 5433) et Redis (port 6380).
make api
Lance l'API sur http://localhost:5243 et applique les migrations. Laisser ce terminal ouvert.
make seed CLASSEUR=chemin/vers/GESTION_COTISATIONS.xlsx
Crée les comptes et la « Tontine du Marche » ; avec CLASSEUR, importe aussi le projet collectif du classeur Excel. Sans CLASSEUR, seule la tontine est créée.
make dashboard
Lance le tableau de bord sur http://localhost:3000.
make mobile
Redirige les ports du téléphone (adb reverse) et lance l'application Android.
make otp TEL=+237670000010
En développement les SMS sont simulés : affiche le code OTP envoyé à un numéro (valable 5 minutes).
make reset
Efface toutes les données de développement (arrêter l'API avant).

Chapitre 1 · un cycle de tontine

De l'invitation au paiement validé

Les scènes s'enchaînent : chacune part de l'état laissé par la précédente. Sur le téléphone, les points blancs montrent chaque toucher ; dans le navigateur, le cercle rouge suit la souris et un bandeau légende chaque étape.

1TéléphoneGestionnaire · 2 min 20

Se connecter et inviter des membres

  1. Parcourir les trois écrans de présentation, puis Commencer.
  2. Se connecter avec le compte d'Awa : 670000002 après le +237, mot de passe Demo2026!. L'accueil salue Awa et liste sa tontine et le projet collectif qu'elle gère.
  3. Ouvrir Tontine du Marche : brouillon, 3 membres, 10 000 FCFA par mois.
  4. Inviter des membres puis Générer un code d'invitation : un code de 6 caractères, partageable sur WhatsApp.
  5. Ouvrir le Profil et se déconnecter.

À retenir : un code fonctionne aussi après l'activation ; dans ce cas l'adhésion suit les règles de la tontine (voir la scène 4).

2TéléphoneNouveau membre · 2 min 57

S'inscrire et rejoindre la tontine

  1. Créer un compte : nom, numéro, mot de passe (8 caractères minimum, une majuscule, un chiffre).
  2. Saisir le code OTP à 6 chiffres reçu par SMS, puis Vérifier.
  3. Sur l'accueil, toucher la poignée de main Rejoindre une tontine et entrer le code de la scène 1.
  4. La tontine apparaît dans l'accueil de Fatou ; elle compte maintenant 4 membres.
3TéléphoneGestionnaire · 2 min 35

Activer la tontine et gérer le tour

  1. Activer la tontine (3 membres minimum) : le tour 1 s'ouvre, Ibrahim est le bénéficiaire, un compte à rebours affiche la fin du tour.
  2. Gérer le tour : les retardataires sont listés, le bénéficiaire en est exclu puisqu'il reçoit.
  3. Tout sélectionner puis Relancer par SMS.

À retenir : un membre qui a désactivé les SMS de rappel dans son profil n'est pas relancé ; les confirmations de paiement lui restent envoyées.

4TéléphoneMembre arrivé tard · 1 min 56

Rejoindre une tontine déjà démarrée

  1. Ousmane se connecte et entre un code alors que le tour 1 est en cours.
  2. L'application répond Demande envoyée : avec les règles par défaut, son adhésion attend la validation du gestionnaire.
  3. Une fois accepté, il passera en dernier dans l'ordre des bénéficiaires et rattrapera les tours déjà ouverts.
5NavigateurGestionnaire · 1 min 23

Accepter l'adhésion, encaisser, valider, vérifier l'audit

  1. Le tableau de bord de la tontine : tour en cours, collecte du tour, membres à jour, reste dû des tours passés.
  2. La carte Demandes d'adhésion : Accepter Ousmane, qui prend le rang 5.
  3. Les règles d'adhésion se règlent sur la même page (interdite, avec validation, libre ; rattrapage ou non).
  4. Paiements : choisir le membre, le tour (les tours passés impayés sont proposés en rattrapage), le montant et le n° de reçu, puis Enregistrer. Le paiement est « en attente ».
  5. Valider après vérification du reçu, ou Rejeter avec un motif obligatoire.
  6. Journal d'audit : chaque action et son auteur, et la vérification de la chaîne SHA-256.

Chapitre 2 · un projet collectif par paliers

« Projet Jeunesse Lumière Santé et Vie »

Le projet est importé de votre classeur Excel : 20 membres, paliers de 15 000, 30 000 et 75 000 FCFA par mois, 44 échéances de mai 2024 à décembre 2027, 302 paiements. Deux membres équipés de l'application le rejoignent ensuite avec un code.

6NavigateurGestionnaire · 1 min 18

Créer un projet, puis lire le projet importé

  1. Projets collectifs puis Nouveau projet : nom, objectif, paliers, périodicité, première échéance, nombre d'échéances. L'engagement maximal est calculé.
  2. Les règles du projet se choisissent dès la création (voir Règles configurables).
  3. Le projet importé : collecté sur l'objectif, solde, journal intègre, et le graphique collecté / attendu échéance par échéance. Survoler le graphique donne les chiffres de chaque échéance.
  4. Les participants triés par reste dû : une case par échéance (soldée, partielle, en retard, à venir). Cliquer une ligne affiche le détail.
  5. Code d'invitation : utilisable plusieurs fois pendant 30 jours.
localhost:3000/gestionnaire/projets
7TéléphoneParticipant · 2 min 49

Rejoindre le projet et augmenter son palier

  1. Dans l'accueil, section Mes projets collectifs, toucher Rejoindre.
  2. Saisir le code puis Voir le projet : objectif, échéancier, nombre de participants.
  3. Choisir son palier (30 000 FCFA) et Rejoindre.

  1. Changements de palier à valider : approuver la baisse de Seydou.
  2. Encaisser un rattrapage : BOUDJEKA Filomene verse 60 000 FCFA sur son retard ; enregistrer puis valider.
  3. Encaisser Fatou : son versement couvre ses premières échéances, il apparaît en avance.
  4. Dépenses : proposer « Achat de médicaments » (450 000 FCFA, facture) puis la valider. Une dépense ne peut pas dépasser le solde.
  5. Les règles restent modifiables ; le journal du projet trace tout.

Le membre retrouve tout, validé

  1. Dans la tontine, Fatou est passée à Payé pour le tour 1.
  2. Payer ma cotisation rappelle la marche à suivre ; Voir mon historique affiche le versement validé et sa référence.

Un membre accepté en cours de cycle passe toujours en dernier dans l'ordre des bénéficiaires : le cycle s'allonge d'un tour. Un changement de palier déjà effectué garde la règle en vigueur au moment de sa demande, même si les règles changent ensuite.

Importer un classeur Excel de cotisations

Le script scripts/import_classeur.py lit un classeur au format « GESTION_COTISATIONS » et crée le projet correspondant : paramètres et paliers, membres, puis chaque cotisation mensuelle (montant, moyen, date) des feuilles COTISATIONS_AAAA.

python3 scripts/import_classeur.py GESTION_COTISATIONS.xlsx --dry-run
Lit le classeur et affiche ce qui serait importé, sans rien écrire.
python3 scripts/import_classeur.py GESTION_COTISATIONS.xlsx --unite 1000
Importe pour de bon (API lancée). --unite multiplie les montants : le classeur écrit « 15 » pour 15 000 FCFA.

  • Les membres deviennent des participants sans compte ; ils peuvent rejoindre l'application plus tard avec leur numéro.
  • Chaque paiement est importé déjà validé, à sa date réelle, et inscrit au journal (« Paiement importé du registre »). Les règles de saisie (partiel, trop-perçu) ne s'appliquent pas à l'historique.
  • Un versement qui couvre plusieurs mois (par exemple 120 000 FCFA d'un coup) est réparti automatiquement sur les échéances suivantes.
  • L'import est « tout ou rien » : une erreur annule tout.

Questions fréquentes

Le téléphone affiche « Erreur réseau » ou « Erreur serveur (504) »

Vérifiez que l'API tourne (make api) et la redirection USB : adb reverse tcp:5243 tcp:5243, à refaire après avoir rebranché le câble. L'application contourne le proxy imposé par certains opérateurs pour les adresses locales, ce qui provoquait l'erreur 504 sur les données mobiles.

Je ne reçois pas le code OTP

En développement, un faux fournisseur SMS écrit les messages dans les journaux de l'API. Utilisez make otp TEL=+2376XXXXXXXX.

Comment donner le rôle de gestionnaire à un compte ?

Un compte qui s'inscrit est membre. Pour l'instant : scripts/demo.sh role +2376XXXXXXXX Gestionnaire. Un écran d'administration est prévu.

Un membre n'a pas de smartphone

Dans un projet, le gestionnaire l'inscrit avec Inscrire un participant (nom et palier) et encaisse ses paiements pour lui. Dans une tontine, le gestionnaire peut aussi l'ajouter par son nom.

Le paiement Mobile Money n'apparaît pas

Il est désactivé par défaut (Features:MobileMoney) puisque l'argent reste hors de l'application.

Limites connues de cette version
  • La validation est faite par le gestionnaire ; un rôle Trésorier distinct, pour un vrai double contrôle, est prévu.
  • L'import Excel se fait en ligne de commande ; un bouton d'import dans le tableau de bord est prévu.
  • Les messages d'erreur renvoyés par l'API sont encore en anglais.
